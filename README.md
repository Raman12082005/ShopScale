# ShopScale

A Full-Stack Multi-Vendor E-commerce Marketplace.

## Project Overview

ShopScale is an interview-oriented full-stack
e-commerce marketplace built to demonstrate
software engineering concepts.

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- React Router
- Zustand
- Axios

### Backend
- Node.js
- Express.js
- REST APIs
- Prisma ORM

### Database & Infrastructure
- PostgreSQL
- Redis
- Docker
- Cloudinary

## Main Features

- Customer, Seller and Admin roles
- Product management
- Product search and filtering
- Shopping cart and wishlist
- Multi-vendor checkout
- Simulated payments
- Order and shipment tracking
- Partial order cancellation
- Inventory management
- Redis caching
- Analytics dashboards

Target: 6–8 weeks
